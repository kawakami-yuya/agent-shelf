# Agent Shelf — AIの道具箱

Claude Code と Codex に持たせている「基本ルール（CLAUDE.md / AGENTS.md）」「スキル」「専門スタッフ（サブエージェント）」「自動タスク」「記憶メモ」「設定」などを、**1枚のページにまとめて見渡せる**ツールです。

- どこに何が置いてあるかを、フォルダの構成図で確認できる
- スキルやルールの中身を、読みやすい形で開ける
- Claude 版と Codex 版で内容がずれていないかを比べられる
- 「存在しないファイルを指している」「同じスキルが二重にある」などを自動で点検し、**改善の提案**を出す

## 安心して使うために

- **読み取りはあなたのパソコンの中だけ**で行います。インターネットへの送信は一切ありません。
- APIキーやトークンらしき値は、ページを作るときに `••••••••` に置き換えます。
- できあがる `index.html` には **あなたの設定内容がそのまま入ります**。他の人に渡したり、どこかにアップロードしたりしないでください。
- このツールがファイルを書き換えることはありません（作るのは `index.html` と設定ファイル `shelf_config.json` だけです）。

## 使い方

### 1. ダウンロード

このページ右上の緑の **「Code」ボタン → 「Download ZIP」** でダウンロードし、好きな場所に展開してください。

### 2. 開く

**Mac の場合**
1. `Agent Shelf を開く (Mac).command` をダブルクリック
2. 初回に「開発元が未確認のため開けません」と出たら、ファイルを **右クリック →「開く」→「開く」** を選んでください（2回目からはダブルクリックで開けます）
3. Python が入っていない場合は、インストールの案内が出るので「インストール」を押してから、もう一度開いてください

**Windows の場合**
1. 先に Python をインストールします：<https://www.python.org/downloads/>
   - インストール画面の最初で **「Add python.exe to PATH」にチェック** を入れてください
2. `Agent Shelf を開く (Windows).bat` をダブルクリック
3. 「WindowsによってPCが保護されました」と出たら **「詳細情報」→「実行」** を選んでください

### 3. 初回だけ：作業フォルダを教える

最初に開くと、黒い画面で「作業フォルダ」を聞かれます。

- Claude / Codex でふだん作業しているフォルダ（仕事用フォルダなど）を、**画面にドラッグ&ドロップして Enter**
- 複数あれば続けて入力し、終わったら何も入力せずに Enter
- 使わなくなったスキルなどを置いている「保管用フォルダ」があれば指定（なければ Enter）

指定しなくても、`~/.claude`・`~/.codex` と、最近 Claude Code / Codex で開いたプロジェクトは自動で読み込みます。

設定は `shelf_config.json` に保存されます。やり直したいときはこのファイルを削除して開き直すか、ターミナルで `python3 build.py --setup` を実行してください。

### 4. 最新の状態にする

スキルやルールを変更したら、もう一度ダブルクリックするだけで作り直されます。

## 画面の見方

| 画面の言葉 | 中身 |
|---|---|
| 基本ルール | `CLAUDE.md` / `AGENTS.md`。AIが毎回最初に読む約束ごと |
| スキル | `SKILL.md`。「〇〇して」で呼び出す業務の手順書 |
| 専門スタッフ | サブエージェント（`~/.claude/agents` / `~/.codex/agents`） |
| 自動タスク | 決まった時間に動くタスク（Claude の scheduled-tasks / Codex の automations） |
| 記憶メモ | AIが作業から覚えたこと（memory） |
| 設定・安全装置 | settings.json / config.toml / hooks |
| 追加パック | インストールしたプラグインに含まれるスキル（名前と説明のみ） |

「改善の提案」では、チェックを入れた提案を **Claude Code への依頼文としてまとめてコピー** できます。貼り付けると、変更内容を確認したうえで対応してくれます（実行前に必ず確認を求める指示が入っています）。

## よくある質問

**Q. ターミナルから使いたい**
`python3 build.py` で作成、`python3 build.py --setup` で作業フォルダの設定をやり直せます。Python 3.9 以上で動き、追加のインストールは不要です。

**Q. 読み込まれていないファイルがある**
作業フォルダの中は 8 階層まで探します。`node_modules` や `.git` など一部のフォルダは読み飛ばします。読み込みたくない場所がある場合は、`shelf_config.json` の `exclude` にフォルダ名を追加してください。

**Q. 最新版にしたい**
同じ手順でダウンロードし直して、古いフォルダの `shelf_config.json` だけ新しいフォルダにコピーしてください。
